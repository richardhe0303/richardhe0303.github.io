About this model: This simulator converts the Python physics engine built during the tennis ball pitching machine project. It models three-wheel spin decomposition, motor torque curves, traction limits, aerodynamic drag, Magnus effect, and multi-bounce behavior. Coordinate system: x = forward, y = left-right, z = height. Launch point is at court baseline height (0.45 m).
